FreshStock 2.0.0 for Windows (64-bit)

Start: open FreshStock.exe. No Python, internet or administrator rights are needed.
The first start can take several seconds while files are checked. About 1 GB of free memory is enough.

1. Overview shows what the program does. Details open with a click, Space or Enter.
2. Predict: choose a date from 2024-06-26 to 2024-07-02, Generate forecast, Reveal outcome, Export report.
   The list ranks all 50,000 series, 100 per page. Find jumps to one city, store, product, for example 0,671,71.
3. Experiment shows the result of the fresh test days and how the settings were chosen.
4. Model health shows historical counts. It does not monitor live data.

Keyboard: Ctrl+1 to Ctrl+4 open the views. In Predict, Ctrl+G generates, Ctrl+R reveals, Ctrl+E exports.
Reports are saved in %LOCALAPPDATA%\FreshStock2\reports (a CSV of all rows and a short HTML summary).

The program is not signed, so Windows may say the publisher is unknown. Compare the file with SHA256SUMS.txt.
Do not turn off Windows security. If Windows blocks it, run it from source instead (see the project README).

"FreshStock cannot start ... was changed": a file was damaged. Extract the ZIP again.
